# Bom Squad Draft Hub

A data-driven League of Legends prep app for Bom Squad, built from one shared JSON object.

## Pages

- index.html - overview dashboard with team identity and grouped external resources
- champs.html - role-by-role player intel, top champs, learn picks, and ban suggestions
- team-comps.html - comp categories, macro plan, and ban matrix with direct champion links

## Data and Styling

- scripts/team-data.js - single source of truth for roster, playstyles, champ pools, comps, and links
- scripts/ui.js - reusable link and parsing helpers
- styles/main.css - shared visual theme and responsive layout

## Run Locally

Open index.html in a browser.
