## 3. How to work here now

- **A rules deploy is the lead's to run.** Claude Code's safety check refuses
  `npm run deploy:rules` from an agent. Before handing it over, run
  `node scripts/rules-check.cjs` (169 mocked requests through the Rules API; no
  emulator, there is no Java here) and
  `firebase deploy --only firestore:rules --dry-run`.
- **An `api/` change goes commit → `npm run deploy:functions` → push.** Markdown
  and spec files under `api/` do not count as drift. Since 27 Sep a push touching
  `api/`, `e2e/` or `scripts/gen-build-info.mjs` also rebuilds Pages and re-runs
  the verify job (before, only `frontend/` did, so a backend-only change left the
  site's build stamp stale and nothing re-checked). The daily health check no
  longer compares the live build with main's newest commit; only a deploy run does.
- **Firestore:** open no listener before `AuthService` sets `userEmail`; a
  collection with its own rules block must also be named in `ownBlock()`.
- **The advisor never sends opponent identity.** Keep it that way: the server is
  the guard, and the provider note is what Riot was told.
- **Local memory is keyed on the folder a chat starts in.** Bom Squad chats start
  in `C:\`; a chat started in the repo folder loads a different, older memory.
- **The lead games on this PC.** Test suites and builds cost frames in League;
  stop background work when asked to pause.
